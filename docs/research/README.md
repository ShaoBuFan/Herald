# research —— 研究文件索引

本目录是对照研究的产出，是作者与 AI 共同的成果。

## 上游与下游

```
docs/notes/    作者的阅读原始笔记（AI 不写）
    ↓  提炼
docs/research/ 本目录：事实、证据、判断
    ↓  固化
docs/decisions/   决策：选择与代价
```

**上游是 `docs/notes/`**：作者的阅读现场记录。本目录的内容应当能从那些笔记追溯上去；反过来，**本目录里的判断在作者读进笔记之前，都还没有经过作者的消化**。

**下游是 [`../decisions/`](../decisions/)**：研究文档末尾的「对 Herald 的直接含义」是设计输入，被编进那份待决清单，等作者定夺。

引语不放这里——它们在 [`../ref/`](../ref/)，本文档引用而不复制（PDF 是唯一真相，引语是抄本）。

## 建议阅读顺序

本目录的三份文件**不是并列的**，而是一条主线的三段：先弄清 ReAct 从哪来，再弄清它到哪去，最后是读原始论文的路径。

| 顺序 | 文件 | 讲什么 | 规模 | 证据层级 |
|---|---|---|---|---|
| 1 | [`react-lineage.md`](react-lineage.md) | **ReAct 之后**：它的提示技巧怎么被原生工具调用（2023-06）与受训练的思考通道先后替换；2023 年无界循环的五条失败机制 | 207 行 | **初版，未经 PDF 逐条复核** |
| 2 | [`react-prehistory.md`](react-prehistory.md) | **ReAct 之前**：推理线与行动线各自走到哪、ReAct 继承了谁、否决了什么 | 683 行 | 七篇 PDF 逐条核对 |
| 3 | [`paper-reading-map.md`](paper-reading-map.md) | **怎么读原始论文**：依赖图、引用矩阵、阅读顺序、尚未取到的 8 篇 | 166 行 | 引用边从 PDF 参考文献表逐条提取 |

**两份主文件为什么没合并**：它们是两次独立调研的产物，证据层级不同（`react-lineage.md` 写于只有摘要页的阶段，`react-prehistory.md` 有七篇 PDF 正文逐条核对）。合并会把这个差异抹平，让未经复核的部分看起来和已复核的一样可靠。各自的「未验证与待补」一节都写明了差异。

**从后往前读也成立**：如果你只关心「现在为什么长这样」而不管历史，直接读 `react-lineage.md` 的 §7（2023 年泡沫的失败机制）与 §9（判决）。

## 设计要点在哪

三份文件末尾都有「对 Herald 的直接含义」一类的小节。**那是设计输入，不是研究结论**——[`../decisions/README.md`](../decisions/README.md) 的待决清单把它们逐条编了号，并标明每条的证据在哪一节。

研究文件里保留原文，是为了让每一条判断都能顺着上文读下来。**改动任一处的立场时，两处都要改。**

## 还没做的

- **ReAct 之前的前史，只覆盖了「推理」与「行动」两条线。** 研究本身的前史（比如 RL 与规划社区怎么看 ReAct）没有涉及。
- **论文批评的论战线索不完整。** `react-lineage.md` §5 记录了 Verma et al. 对 ReAct 的批评，但没有覆盖 2023–2024 年围绕 CoT 有效性的那批工作（如 CoT 是否只是表面模式）。
- **中文材料与工程博客未纳入。** 本目录只取一手论文与官方文档。
- **没有实测。** 全部结论来自阅读，任何一条都没有在本机复现过。
